# p3c 格式配置

`eclipse-codestyle.xml` 原样取自 [alibaba/p3c](https://github.com/alibaba/p3c/blob/798005974de69f69e2235d5bd3810fcda10a469c/p3c-formatter/eclipse-codestyle.xml)，遵循 [Apache License 2.0](LICENSE-p3c.txt)。更新配置时，替换 XML 并同步来源链接。

Spotless 8.10.4 使用 Eclipse JDT 4.26 执行格式化，并统一 UTF-8、LF、行尾空白和文件末尾换行。p3c 的 PMD 检查规则不属于格式化配置。
