# 验证边界

产品决定应保证的行为、支持范围和优化优先级；本页只规定验证投入与证据解释，不增加产品承诺。

## 性能验证

[工作量与服务端软目标](../product-decisions/decisions/workload-budget.md)及[基础设备参考](../product-decisions/decisions/device-quality.md)用于比较优化收益。参考设备、100 人成本目标和面向未来 Bukkit 的 200 人观测范围保留在产品层；这些数值不作为当前开发期间每次变更的硬验收门槛，也不豁免普通错误隔离与主循环保护。

300 人极限压力测试用于探测系统上限，不承诺该规模下正常服务。根据改动涉及的工作量选择最小相关验证，实际帧率、MSPT 和 lag spike 的结果必须附对应内容规模和运行环境；未执行完整压测不记为性能达标。

## 视觉验证

固定场景与人工/AI 检查边界见[视觉一致性验收](../standards/conformance.md#视觉一致性验收)。文档校验、单元测试及基础视觉检查各自只能证明已覆盖的层级，不能代替真实游戏、联动或高级效果的验收。
