# GUI Molang 解释语义

本页定义普通 GUI 路径下 Molang 表达式的独立准备、动态值与动态调用语义。路径选定见[执行用途与主体资格](molang-runtime.md#执行用途与主体资格)，Java 扩展契约见[共同声明](molang-declarations.md)，AOT 规则见[静态语言](molang-static-language.md)。两条路径共用 `MolangContext`、冻结声明、源执行帧和宿主效果出口。

## 独立准备与来源

- **按需准备**：宿主按动画集固定来源命名空间、接收模型语义选项与用户函数获取能力，Semaweave 仅接收当前消费的 Portable Program 字节。准备期校验输入全部结构（含未执行分支）并产出不可变绑定求值树（固定操作种类、槽位、访问方式、Java 调用形状、权限、归属与候选集合），动态值类型留到执行期检查。
- **共享环境与槽位**：同一动画集代共用一个解释环境，普通变量与 Roaming 规范名登记为只追加的稳定整数槽位，局部变量与参数槽位归属单程序。并发准备仅同步名称登记；准备失败时已登记的无值名称可保留。
- **用户函数延迟绑定**：准备期仅绑定函数名与精确来源身份（本地与默认补全保持独立身份），函数体首次调用时才读取准备。局部已加载程序子集不能作为函数不存在或类型固定的证明；仅完整有效的本地及默认来源范围可写入负缓存。未被消费的损坏函数体不影响其他表达式准备。
- **用户函数调用步骤**（已确认缺名或参数数不符时直接返回 `missing`，不求参、不计深度）：
  1. 检查源帧活跃函数深度；达第 33 层时在取函数体和求参前终止当前顶层表达式。
  2. 按固定来源身份获取并准备函数体（递归仅引用身份，不展开闭包）。
  3. 确认缺名或参数数不符则返回 `missing`；函数存在但读取、内容或绑定失败则结束当前 GUI 实例。
  4. 从左到右求参，建私有局部变量并执行函数体（继承当前查询环境、源变量与源权限）。
- **继承公共契约**：[来源版本除零选项](molang-static-language.md#来源版本与除法)与非有限值策略在解释环境内固定（默认补全与公共函数沿用接收模型选项）；数值投影、逻辑短路、[运算符分组](molang-static-language.md#运算符分组)、[循环与函数深度](molang-static-language.md#循环与函数深度)、[引用与箭头](molang-static-language.md#引用与箭头)及词法控制流沿用公共语言契约。

## 数值消费

解释路径沿用宿主[算术数值策略](molang-static-language.md#来源版本与除法)：闭集数学函数接纳非有限中间值并将定义域外/溢出结果归一为 `+0`；输入准入阶段校验字面量与外部动态值；承诺返回有限值的 Java 方法直接信任，可空返回按共同声明归一。

| 消费边界 | 有限性检查与失败后果 |
|---|---|
| 条件、逻辑、比较、循环次数、索引及整型转换 | 使用前检查，防止非法中间值变为有效条件或索引 |
| 变量、字段、Roaming 写入，以及用户函数参数与返回 | 交付前检查，失败时不发布写入也不进入函数体 |
| 获准的 Java 实参 | 从左到右逐参检查，失败时后续实参与声明方法均不执行 |
| 顶层有值结果 | 交付前检查，失败结束本实例；单纯丢弃的数值结果不额外检查 |

消费边界前已执行的获准效果保留不回滚；普通动态类型失配也在实际消费点触发失败。

## 动态变量与缺值

- **槽位与赋值**：普通变量与局部变量按稳定整数槽位访问实例或当前激活帧的动态值数组，同时保存值与缺值状态。赋值、传参、返回和 `??` 原样保留 `missing`；未赋值普通变量与不存在字段读出 `missing`；本次激活未初始化的 `t.*` 读出未指定值（可能见复用缓冲残留；参数初始化、已写局部值、递归与实例间隔离不变）。标量消费时按[公共数值投影](molang-static-language.md#对象-presence)供应 `+0`/`false`，不回写变量槽。
- **值域与按需扩容**：普通赋值直接记录右侧类型（`0` 为数值、`false` 为布尔、`null` 为无类型缺值，Java 返回缺值保留声明类型）；`String`、只读数组和精确引用沿用[共同声明](molang-declarations.md#值与-presence)。程序首次进入时按需扩容实例数组并保留旧值；外部按名只读查询未知名称直接返回 `missing`，不登记新槽位。
- **Roaming 集成**：`Roaming` 保持初值 `+0` 的必有值 F32，安装时经环境 `newRoamingState(role)` 创建状态对象。环境仅共享名称-槽位目录，数值、已声明成员集与 dirty 标记归属实体实例（仅本实例进入的程序或同步输入登记成员）。外部 full/patch 可先于程序准备引入名称（full 清零本实例已知字段，patch 仅覆盖携带字段），宿主在网络边界按名称转换外部编号。

## 平面结构体与字段写

脚本结构体表示为不可变平面 `Map`（字段值限 F32、BOOL、`String` 或 `missing`，支持动态增改类型；赋值/传参/返回共享旧快照，写入发布新快照）。Java record 与只读数组保持不可变。

字段写按固定三步执行：捕获可写变量槽位与当前接收值 → 求值右侧表达式 → 发布新结构体：
- 接收值为缺值、F32 或 BOOL：新建仅含本次写入字段的结构体。
- 接收值为脚本结构体：保留其余字段并更新目标字段；接收值为变量中的 Java 平面 record 时，转为独立脚本结构体。
- 接收值为 `String`、数组或引用，或字段值非法/右侧求值失败：不发布更新（右侧已发生的其他效果保留）。

即使右侧重写该变量或懒加载函数触发扩容，第一步捕获的接收值不变，最终按逻辑槽位写回当前数组（已有别名仍见旧快照）。临时 Java record 字段写执行相同前两步与校验，仅省去写回。对缺值或标量读普通字段返回 `missing`，访问未声明 Java 成员或非法引用则失败。写入缺值与删除字段等价。

## 比较

- F32/BOOL 混合比较、对象与标量投影比较、同类 `String`/数组内容比较及引用身份比较沿用[公共规则](molang-static-language.md#对象-presence)；不同类型对象一律判定不等，不调作者 `equals`。
- 脚本结构体忽略缺值字段后按字段名集合与字段值比较（与顺序无关）；Java record 保留声明类型，经字段写转为脚本结构体后按结构体比较。
- 缺值与缺值相等；缺值与非缺值 F32/BOOL/`String` 分别按 `+0`/`false`/`""` 比较；缺值与非缺值结构体、数组或引用一律不等。比较不改变 `??` 观察结果。

## 冻结 Java 调用

- **调用与逐参筛选**：无括号访问与空括号调用均视为零参调用。先核查固定 ACTION 权限、subject 资格与参数个数，再从左到右逐个求参（每参求值一次）；任一实参使剩余候选全部失配时立即抛运行时类型错误，后续实参与声明方法不执行。
- **重载决策**：按当前实参实际类型筛选，精确匹配优于标量转换（普通 `null` 对所有可接纳候选等级相同，带类型缺值按声明类型匹配）。全部实参通过后按[逐参数支配及规范 JVM 成员排序](molang-declarations.md#作者签名)选定唯一方法。默认值仅补给省略位置，显式 `null` 计入 `argc`。
- **调用计划复用**：同环境内按符号、访问形式和实参数量复用只读调用计划（缓存签名、`MethodHandle` 与适配链接；单候选直调，多候选逐参筛选），执行时传入本实例 receiver 与 context。调用计划不持有表达式、实体或上下文，随 store 解释环境退休。
- **箭头与加载隔离**：箭头仅切换查询环境，ROOT 从源帧取上下文与 binding，源变量、用户函数、权限、深度、`defer` 与效果归属留在源实体。解释与 AOT 绑定相互独立，不同 `Class` 或加载环境的同名声明互不通用。

## 实例、驻留与失败

- **共享与实例边界**：`AnimationStore` 共享不可变绑定程序、名称目录与调用计划；每个 GUI 实例独占变量、局部激活、controller、组件与上下文，沿[实体执行权](entity-lifecycle.md#执行权与任务交接)在单实体串行窗口内运行（当前实现不支持重入）。同轮复用 `MolangContext` 与根外壳，同步退出清临时借用；根局部缓冲按程序需求复用（引用可活至覆盖或实例关闭），递归函数各持独立局部帧，箭头共享当前激活帧。程序驻留与退休见[动画资源所有权与退休](../model-management/client-resources/overview.md#动画资源所有权与退休)。
- **`cache-only` 边界**：可从本地已有未绑定输入解码并在内存绑定；取得期输入不足返回未命中，求值期读取失败直接结束当前实例（不回退已有效果，不触发网络拉取），见[用途与派生物](../model-management/client-resources/overview.md#用途与派生物)。
- **异常与中止分类**：
  - **正常返回**：合法缺值、完整来源证实的缺名、参数数不符、权限门禁拒绝。
  - **拒绝准备**：结构损坏或链接失败。
  - **结束当前 GUI 实例**：运行时类型错误、声明方法抛真实异常、已消费输入读取失败（已有写入与动作不回滚，不触发整程序替换；普通失败实例废弃不复用，共享程序与其他实例不受影响）。
  - **仅截断当前表达式**：用户函数深度超限，窗口退出后继续执行后续表达式。
  - **异常传播与严重错误**：内部调用原样向上传播，宿主在顶层统一报告一次（顶层身份与原 `Throwable`）；严重错误与清理失败按[Molang 故障分类](molang-runtime.md#求值失败)处理。
- **栈深度与取消点**：仅限制活跃用户函数深度（不限制语法树或箭头嵌套深度）。取消检查位于准备期的入口/解码绑定交接/函数读取点，以及执行期的入口/循环回边/函数读取前后/顶层交回点；取消后不发布结果，资源释放等待实际工作退出。
- **取舍与验证**：省去整集静态分析的代价包括名称目录常驻、高槽位稀疏数组、动态扩容与分派、结构体复制及首次读函数体开销。验证入口见[Molang 集成验证](../../verification/molang-declarations.md)，当前覆盖与性能缺口见[动画问题](../../status/known-issues/animation.md)。
