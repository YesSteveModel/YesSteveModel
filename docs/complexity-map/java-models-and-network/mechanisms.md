| MN-07 Domain 有限工作与 owner-tick 提交 | Catalog、client/server runtime 各自接纳完整有限链，计算 worker 不等网络、host 或其他 worker。服务端 chunk 与独立图共用字节 runtime；旧图 flight 失去加入资格后仍占容量直到物理结束。客户端在原容量内划出本地玩家 worker；Dispatch 集中裁决同节点迁移、领取与排空，原 owner 保留取消和终态。删除隔离会使本地玩家等待后台长队列；把调度器变成业务 owner 会增加第二完成权威。 | `A-WORK`、`D-LOOP`；**Derived**。主循环与独立容量是义务，队列和 worker 形状可替换；固定专用容量牺牲一个后台计算位置。 | **Fact**：`ClientResourceScheduler`、`ReloadableModelCatalog.ActiveScan`、`RuntimeContentStore`、`ServerResourceRuntime`、`ClientModelRenderTargetManager`；[有限工作理由](../../architecture/runtime/overview.md#有限工作与发布)与[客户端调度](../../architecture/runtime/overview.md#客户端资源调度)。Exact session close 不 drain 共享 worker；进程 close 先结束 owner，再封口并排空调度。 |

| MN-10 集中需求与独立安装 | ClientDemandCoordinator 独占活跃页面、hover、selection 与每实体的连续状态、用途和反馈；binding 仅保留指派、完整安装及精确失败。Ready 通过独立 receiver lease 进入原 barrier，Busy 不等待；世界旧合法安装保留；卡片失去展示资格则退休。只有左侧名称观察真实玩家安装等待，卡片名称不消费等待。纹理入口接收 Ready，不保存待进入意图。选择发送与预取独立，ID 9/10 仅关联当前 disposition；反馈有限且不回滚 authority 或清失败资格。删协调会让短命意图发包、用途交接取消有效工作或把 Ready/Accepted 当作安装。 | `D-FALLBACK`、`D-HOST-FALLBACK`、`D-GUI`、`A-CONTINUOUS-DEMAND`；**Derived**。集中规则收缩跨 owner 状态组合；仍支付用途 anchor、每实体 timeline 和有限反馈状态成本，不以类数或 LOC 证明归约。 | **Fact**：`ClientDemandCoordinator`、`AnimatableEntity.install`、`EntityExecutionLifecycle.tryInstallation`、`EntityModelBinding.accept`；Coordinator/cache、binding/真实 JNI、协议来源和 Busy barrier 测试通过；[需求交接](../../architecture/model-management/demand/overview.md#用途准备与独立接收)、[反馈](../../architecture/model-management/demand/overview.md#选择反馈)与[安装](../../architecture/animation/entity-lifecycle.md#完整安装与替换)。Cache、Flight、transfer 与 host publication 继续归 MN-06/17–19；领域失败资格归 MN-20。 |
| MN-11 Exact session、业务准入与迟到隔离 | 入队/应用核验 Connection；Hello 先经无状态开发版本门禁，ACCEPT transport commit 再建立稳定 `BusinessSession`，Selection、PlayerState 与控制消息不等待 catalog `ACTIVE`。协议失败/断连撤销业务资格，catalog failure 只关闭 publication/resource owner；publication/transfer 仍使用各自非零递增 ID，旧 terminal 不重开。Session 还持当前成员有界的 preview 观察/token，通知、移除重加与结束撤销旧缺图发布资格；DATA 解码复用发送 token，页面只查询。删隔离会串服或把旧结果接到新会话；绕过版本门禁会让开发 wire 被稳定版策略误接纳；合并业务与 catalog 生命周期会让目录失败错误中断 gameplay。 | `D-SESSION`、`D-SESSION-FAIL`、`D-WIRE`；**Essential**，身份空间隔离与局部失败直接有产品依据。 | **Fact**：`VersionCompatibility`、`ClientModelSession.onServerHello`、`ClientSessionRuntime.beginConnection/businessSession/runIfCurrent`、`ServerModelService.runIfCurrent`、`ClientAssetTransfer`；`ModelSessionContractTest.differentDevelopmentProtocolVersionFailsOnlyTheModelSession` 断言失败保持 session-local。[session](../../architecture/network/implementation/transport-and-session.md)。门禁不新增协商状态或 wire；BusinessSession 不新增 wire identity，publication/transfer ID 仍存在，不能把表现路径的 generation-free 扩大成整个协议无 identity。 |
| MN-12 Typed admission 与业务局部 assembly | 各 request 保留自身 natural key、权限、coverage、optional terminal；整份 descriptor 先验证，再在 source acquisition 前建立既有 transfer owner。Preview 只用 slot/model/container 请求，以唯一 final range 动态定长并做 16 MiB/128 MiB 与媒体解码；preview 正常空结果为 ABSENT；客户端按原 remote Manifest 区分来源，独立图确定性媒体拒绝可记缺图，其余失败不建立观察；icon/cover 保留 descriptor/hash 与 UNAVAILABLE。管理 query/主目标 chunks/upload 共用 ID，独立接纳授权；完整清单不成为资格，上传 header/admission/offset coverage/严格 commit 只属于一个请求。删验证会把半份/错权限结果当成功，给 preview 恢复 hash 则新增无依据版本 authority。 | `A-TYPED`、`D-CHUNKS`、`D-VALIDATE`、`D-ACCESS`；**Derived**，typed owner 是承载不可删验证义务、获取窗口与图片弱关联的方案。 | **Fact**：`ServerAssetTransfers.decodePresentation/validatePresentation`、`ClientAssetTransfer.PresentationChild/QueryChild/UploadChild`、`RenderTargetChunkPlan`、`ServerModelSession.Effect`；[资产传输](../../architecture/network/implementation/asset-transfer.md)。没有晚绑定 callback owner；构造异常、enqueue reject 与 accepted close 仍归 MN-14。 |
| MN-13 仅超帧 action 的顺序 children | 完整 descriptor 超帧才顺序启动有限 children，父只聚合结果；取消阻止未启动项，先前 exact cache commit 不回滚。删 parent 会丢完整动作结果，总是逐项则增加 ID/终态。 | `A-FRAME-BUDGET`；**Derived**。 | **Fact**：`ClientAssetTransfer.MetadataAction/ModelAction`；[超帧理由](../../architecture/network/overview.md#typed-capability-与业务组装)。分片阈值是架构预算，不是 Minecraft 硬性单包上限；提高预算不证明所有大动作都无需分片。 |
| MN-14 单一 accepted dispatch 与 range capability | Enqueue 是完整 packet 集合的 ownership frontier；global worker 持有 source、玩家 FIFO、cursor、限速/背压/retry 和 close，只构造当前有界帧。Bytes、共用于 chunk/独立图的 byte lease 与 file range 由一个 range packet 的三种 capability 解释读取和释放；拒绝或构造失败仍由业务 owner 关闭未转移能力。删除会扩大驻留、重复范围/终结、重复推进或双关闭。 | `A-DISPATCH`、`D-ADMISSION`；**Derived**。 | **Fact**：`RangePacket`、`ResourceDispatchWorker.enqueue/visit`、`ServerAssetTransfers.submit`；[dispatch 理由](../../architecture/network/overview.md#分发所有权与负载保护)。接纳时授权不因后续撤权重判；retry/cursor 不是第二套权限 authority。反向图片 cursor 由 client tick 按 writability/实际 bytes 限速推进；关闭只撤自己的 bytes 引用。 |
