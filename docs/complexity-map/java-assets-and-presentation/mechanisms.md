| AP-01 冻结实际解析闭包 | Capture 深拷贝实际读取的 bytes 并固定目录观察，scan/compile 复用 parser；直接重新读取来源会让身份与产物消费不同内容，archive 的下一次读也可能覆盖旧借用。 | `A-CAPTURE`；**Derived**。一致输入是义务，冻结 VFS 后重跑 parser 是当前实现选择。 | **Fact**：`ModelParser.capture`、`CapturedSourceData.freeze`、`RawModelImporter.convert`；`ModelParserTest` 验证冻结输入与副本关闭。[capture 理由](../../architecture/asset-pipeline/overview.md#冻结输入与单向转换)。不保证整个可变文件系统在同一个物理时刻快照。 |
| AP-02 分层准入与逐块验证 | Metadata prefix 建立 identity/Manifest 描述，容器 reader 独占容器版本准入，schema reader 复用无状态开发版本门禁；实际 chunk 仍核对 size、hash 和适用解码。删除后，目录可见会被误当作内容有效，开发版本也可能被未来放宽的稳定版策略误接纳，损坏或跨表示 bytes 可进入资源构造。 | `D-META`、`D-VERIFY`、`D-IDENTITY`、`D-FREEZE`；**Essential**，由按需访问、精确表示与开发制品不可推断兼容的产品契约直接要求。 | **Fact**：`VersionCompatibility`、`AssetContainerReader`、`ModelFileView.readMetadata`、`ChunkDecoding.decodeZstd/validateDirectPayload`；`VersionCompatibilityTest` 验证开发版本门禁。[分层验证](../../architecture/asset-pipeline/implementation/container-and-validation.md)。版本门禁是纯函数，不新增状态、owner、生命周期或恢复分支；结构/当前 profile 检查不能充当完整标准 conformance。 |
| AP-03 Raw PNG 的用途驱动重编码与失败回退 | Raw 转换复用合法的 JPEG/WebP/AVIF 等既有压缩表示，只让 PNG 进入用途策略；编码成功即采用结果，即使制品变大，只有可处理的 codec I/O 失败才保留原图。删除格式门禁会重复处理既有压缩表示，删除失败回退会把可用输入变成转换失败。 | `D-IMAGE` 与 `A-IMAGE`；**Derived**。用途保真义务不可删，输入门禁、codec/尺寸策略和失败回退是可替换方案；legacy 解码期图片归约另归 NR-17。 | **Fact**：`RawImageCompressor.compress`、`ImageEncoder`；`RawImageCompressorTest` 验证复用、结果采用与失败回退。[处理位置](../../architecture/asset-pipeline/implementation/conversion-and-export.md#图像处理的位置)。策略效果与成本证据见 [Q-04](open-questions.md#q-04)。 |
| AP-04 连续页面需求与迟到结果处置 | Coordinator 的 PageScope 保存语义成员、稳定卡片端点和连续起点，统一计算模型与图片的分级准入；PageImages 保存惰性取得、提交、slot 终态与独立图片 use，ResidentImages 集中内容关联和消费者计数，manager 保留唯一物理释放责任；相同内容重建/resize 保留 scope 和实体，真实页面变化封口旧 scope。页面以循环游标分配每帧有限的新准备名额，提交拒绝也推进游标；已有绑定的动画不占新准备名额。同卡获准的 Ready 绑定与冷图 CPU 准备归同一次任务，共享图只交给一个解码任务。页面绑定世界流程，资源 action 绑定原连接；活跃帧完整交接后才结束页面使用，迟到结果不能复活旧页面。目录层级以完整地址隔离来源，展示跳过来源前缀；Ctrl 路径动作只消费发布位置或已验证本地证明，不进入 demand。删除会让短命页面启动准备、内部重建反复等待、突发准备无界或图片悬挂。 | `D-GUI`、`A-PAGE`、`A-CONTINUOUS-DEMAND`；**Derived**。页面、图片宿主与共享资源的责任仍不同，但不再分别保存需求规则；成本为活跃 scope、循环游标、帧内任务与共享图归属、图片 slot 推进、资源侧内容证明和 use 计数；驻留命中先于取得。公平预算与任务分组可由保持同次任务、持续进展及退出交接的等价调度替代；删除共享 owner 会恢复逐页读取、解码和注册，其删除条件是宿主已有等价的内容关联与独立消费者能力。图片提交时固定生成用途，batch 与 host 在接纳点转移独立像素能力；取消不依赖旧页面推进；传输结束后逐条交付图片，不让整批完成约束单图交接。 | **Fact**：`ClientDemandCoordinator.PageScope`、`PageImages`、`CatalogPageFrame`、`GuiFrameTasks`、`ClientDemandCoordinatorTest`、`GuiFrameTasksTest`；[页面 owner](../../architecture/client-presentation/implementation/page-runtime.md#页面与资源-owner)。Repository 保留 exact action、ABSENT 和 cache 提交；实机反复翻页/纹理回收仍未验。 |
| AP-05 展示资格与独立 GUI 准备 | 配置与连续交互授予展示资格；自动 GUI 最多离线，交互准备另受页面准入约束。页面推进发布 eager 政策，eager 不请求或消费 preview，配置切换不重置连续起点。移出撤销卡片安装、私有状态和动画引用，已接纳准备继续归原 owner；同目标 GUI 与 FULL 选择各自推进固定用途，新使用建立前保留来源 anchor。模型列表 tick 只取得 Ready，帧领取独立 lease 后才结束来源 anchor，安装结果在任务交接后显式通知。纹理入口只接收完整预览 Ready，接收方先持独立使用。删除分离会让 cache 或预览生成重新授予展示资格，或在零 unused cache 交接时丢失有效使用。 | `A-PREVIEW`、`D-JOIN`、`A-CONTINUOUS-DEMAND`；**Derived**。成本为稳定卡片端点、临时实体 scope、Ready claim、一个交互准备和一个选择准备；不保留卡片 FULL 等待或导航恢复状态。自动准备只创建默认 body；GUI 不探测或借用 FULL，中央动画预览取得独立 FULL。领取协议可在资源 owner 直接提供等价的独立接收与结果交接后归约，不能以 Ready 代替展示或安装资格。 | **Fact**：`ClientDemandCoordinator`、`CatalogModelCardState`、`AnimatableEntity.retire`、`PlayerModelScreen.openTexturePage`；[展示实现](../../architecture/client-presentation/implementation/page-runtime.md#页面主流程)。生产接缝的时间、退休、独立 lease 和入口测试不替代真实输入、视觉与 GPU 成本观测。 |
| AP-06 转换 staging 与重开验证 | Raw/legacy 转换先形成独立 staging，验证 identity、逻辑 payload 和存储描述后才进入 converted object/目录 candidate；失败清理本次半成品。只删门禁会把“转换过程成功”当成“当前容器可读”，或暴露部分产物。 | `A-ONE-ARTIFACT`、`D-FREEZE`、`D-SOURCE`；**Derived**。跨输入格式统一出口带来产物交接；来源只读与完整内容仍是独立要求。 | 架构事实见[转换出口](../../architecture/asset-pipeline/implementation/conversion-and-export.md#发布与失败)及[单向投影](../../architecture/asset-pipeline/implementation/conversion-and-export.md#历史输入的单向投影)；验证入口 `LegacyModelImporter.stage`、`RawModelImporter.convert`、`ConvertedObjectStore`。保留 staged 容器再读是当前策略，未以文档替代全部 golden/真实导入测试。 |
| AP-07 实际来源准入与 schema 分离 | Schema reader 接受合法无图容器；Catalog 只对实际 direct 成品要求声明且完整解码内嵌 preview，raw/builtin/legacy 内部结果允许缺图。来源由 resolver 调用链固定，不能由扩展名、`origin_ver` 或 cache 猜测。删除分层会拒绝合法内部来源，或让缺图 direct 绕过产品门禁。 | `A-DIRECT-ADMISSION`、`D-SOURCE`；**Derived**。按来源准入是产品选择，单独 policy gate 是当前方案。 | **Fact**：`DirectContainerAdmission.requireEmbeddedPreview`、`ModelSourceResolver.resolve/resolveMaterialized`；[preview/export](../../architecture/asset-pipeline/implementation/conversion-and-export.md#preview-取得与显式-export)。完整来源矩阵与跨平台媒体仍未验。 |
| AP-08 弱关联 preview cache 与完整 export | 独立图按 `ContainerId` 弱关联，普通服务端读取不解码，与 chunk 共用字节 runtime。唯一 store 的持久成功和显式 reload 撤销旧缓存及旧 flight 发布资格，活动 lease 与物理容量仍由原 owner 维持；strict commit 在原 session/member 资格内原子替换，通知不反转持久结果。Client tick 的总 operation admission 跨 probe、target、host 与写出持续持有容量和终态；integrated environment 拥有固定批次、精确输入与提交资格，结束时撤自身需求。删除独立 cache 会重复取得图片；回写容器会制造身份/目录循环；删除总 admission 会无界保留 candidate/pixels/source。 | `A-PREVIEW-CACHE`、`A-WORK`、`D-FREEZE`、`D-SOURCE`；**Derived**。来源保护、完整输出与成功结果是产品义务；弱关联、共享字节保留、替换资格、串行批次和统一 admission 是可替换设计；删除平行读取链，增加一个旧 flight 存活集合及提交/reload 失效成本。图片版本在原替换门禁内同步更新，不依赖尽力通知；独立图读结果、session 成员观察和 Catalog reload 共同防止旧像素发布。该投影可在原 owner 直接提供等价版本能力后删除。封闭内容复用媒体资格，原 operation 直接派发解码；独立像素引用与同步借用保留到实际使用结束。成本为退休、能力交接与取消清理，消除同次存储／上传的重复解码，不再协调客户端字节额度。 | **Fact**：`ClientPreviewGenerator.tick`、`PreviewStore`、`ServerResourceRuntime`、`PreviewRepairBatch`、`ServerPreviewWork`、`ModelExporter.export`、`ModelExportService.Environment`；[preview/export](../../architecture/asset-pipeline/implementation/conversion-and-export.md#preview-取得与显式-export)、[共享字节保留](../../architecture/model-management/server-resources/overview.md)与[管理传输](../../architecture/network/implementation/asset-transfer.md#receiver-local-assembly-与-publication)拥有时序和容量。共享 render owner 与 target 能力；局部测试与宿主证据范围见[模型管理问题](../../status/known-issues/model-management.md#导出与管理补图)。 |
| AP-09 音频规范化、完整计价与分层验证 | Raw/legacy 统一声音表示；高 packet-rate Opus 的 R/T 选择复用实际 writer，对固定其余内容计算完整容器长度。M1 只检查 descriptor/定位，prefix 只取得首块，M2 顺序 feed 全部块到 EOF，export 原样复制并重开复验。删除统一表示会让 producer/consumer 对 codec、frame 或布局分歧；用估算公式替代实际 writer 会改变选择；把 M2 并入 catalog 浏览会预读全部声音。 | `D-SOUND`、`D-MIGRATION`、`D-JOIN`、`D-CHUNKS`；**Derived**。声音可播放、单向迁移和按需内容是义务；候选选择、首页/块定位和分层验证是当前方案。 | **Fact**：`RawModelAssembler`、`SoundMediaGeneration`、`SoundMedia`、`LegacyModelImporter`、`BuiltinModelMaterializer`、`ModelExporter`；[音频转换](../../architecture/asset-pipeline/implementation/conversion-and-export.md#音频内容转换)。局部测试覆盖候选选择与完整验证；来源、平台与游戏覆盖见[格式问题](../../status/known-issues/format-and-schema.md#codec导入与平台)。 |
