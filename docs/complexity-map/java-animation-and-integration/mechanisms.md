| AN-01 实体私有求值状态 | 同一 target 的不可变 module、catalog、绑定与模型资源可共享；每个 owner 独占 holder、instance、controller、random、physics、deferred、Roaming 与骨骼状态。Body 只产生命名 Roaming 源结果，主线程在两侧交接后投影到精确 arm/vehicle；双手与背景仍共用第一人称时间线。合并可变状态会污染另一 owner 的历史。 | `D-ENTITY`；**Essential**。隔离是义务，不要求通用 runtime 锁。 | **Fact**：`EntityExpressionRuntime`、`AnimatableEntity`、`AnimationProcessor`；[实体 owner](../../architecture/animation/implementation/entity-and-frame-state.md#实体级所有权)与[Roaming](../../architecture/animation/implementation/state-inputs-and-sync.md#roaming)。Retire 永久终结 owner；reset/reload 保留新使用资格。兼容纹理保留既有历史，新内容仅承接位置历史。Cleaner 只兜底独立 lease。 |
| AN-02 异步实体任务的串行与汇合 | 主线程为每 owner 保存一个待交接 Future；对应 get 覆盖更新及完整 finally，之后才开放更新态。单实体可以早 get，调用末尾仍完整 drain 全部登记任务与投影。中断不提前释放。删除 get 会让求值、Extract、draw 或重绑重叠。 | `A-AN-01`；**Derived**。单实体顺序必需，具体调度方式可替换。 | **Fact**：`AnimationParallelTicker`、`EntityExecutionLifecycle`；[任务交接](../../architecture/rendering/implementation/frame-execution.md#任务发布与并发边界)。通用 owner barrier、isDone 读取旁路与逐访问跨线程资格探测已退出普通路径。保留局部绘制借用、独立编译 inbox 交付和共享资源同步；它们不保护普通实体访问。真实 Forge 接线与成本仍需运行证据，见 [Q-01](open-questions.md#q-01)。 |
| AN-03 跳过求值时维持逻辑时间 | Owner 独占已接纳 tick/time 两条基线，首次组件采样为零跨度；限频恢复一次消费累计跨度，observation 与姿态复用不移动基线。Tracker 不再重复门禁；把每次执行都当固定一步，会使降频实体减速或重触发。 | `A-AN-03`；**Derived**。降频补偿状态依赖当前选择；实际呈现时间推进和重复观察不重复动作仍有独立义务。 | 行为与时间关系 **Fact**。距离/可见性直接减少求值次数，支持降低 CPU 工作量的 **Inference**；单纯修正动作语义不足以解释为何按距离减少执行。第一人称手部 animation-only 复用同一逻辑时间与限频，重复观察不新建 token；背景完全不调用求值。具体阈值的选择理由仍 **Hypothesis**，没有比较测量。`AnimatableEntity`；整体表现与因果保持见 [O-07](open-questions.md#其他实现边界)。 |
| AN-04 多 pass 共用历史的输出分离与姿态恢复 | 常规 level 复用 canonical 输出，其他 context 可重新求值；coded 姿态修改在后续 pass 前恢复。第一人称同 owner 持有三份独立持久输出；准备资格与实际有效性共同门控帧内重复消费，跨帧保留 schedule；背景声明初始数组绑定实际 target/GeoModel，与活跃属性分离，inplace 换模也重建。删除协调会让某 pass 的头部隐藏或姿态覆盖另一个 pass，或使背景采用动画姿态/旧资源。 | `A-AN-02`；**Derived**。选择共用 controller 历史及骨骼输入后才需要跨 pass 恢复。 | **Fact**：`AnimatableEntity.update/computePose`、`PlayerAnimatableCapability.recoverLastCodedAnimation`；[输出与 context](../../architecture/animation/implementation/entity-and-frame-state.md)。`FirstPersonModelState` 与真实 JNI owner 测试提供局部证据；宿主放置和 shader 范围见[渲染问题](../../status/known-issues/rendering.md#重复消费与第一人称)。Canonical pose 的复用不证明本次 draw metadata 仍正确。 |
| AN-05 动作与观察的阶段门禁 | 顶层表达式固定 ACTION 许可，callee effect 只门禁该次调用；ACTION/subject 拒绝先于实参。每轮共用 context，表达式退出只清理局部借用，不以末尾许可判断整轮效果。获准动作进入有界 batch，实际顶层来源、callee 来源与首次失败保留到必要 hook、效果验证和 owner 资格全部成功后提交。来源轮在提交前关闭，本地 sync 在同一 barrier 内创建下一轮；删除闭合交接会使合法 sync 被活跃轮重入检查拒绝。删除动作门禁会使动作随 pass 数增加；删除 batch 会暴露部分逻辑结果。 | `D-EFFECT`、`A-AN-02`；**Essential** 指动作次数、来源和提交义务。Provider 权限收窄、动态权限栈与父 mask 恢复不承担这些义务。 | 结构 **Fact**：`ProgramRole.entryPermissions`、`MolangContext`、`EffectBatch`、`EffectTransaction`、`EntityExpressionRuntime`；[Binding](../../architecture/animation/implementation/molang-runtime.md#binding-与-invocation)。原 owner barrier 排序安装、执行与封口；组件成功 begin 前缀逆序 end，主失败优先；OOM 从局部求值上达实体操作边界，不提交本轮效果。Context 不取得组件或 lease 的关闭权。声明实现固定目标与载荷，runtime 仅保存通用申请；载荷与来源快照仍有成本；外部 commit 没有跨系统回滚。手部沿用 level 门禁，背景只同步资源；headless oracle 不证明真实 Forge 的 once-only 提交，运行范围见[动画问题](../../status/known-issues/animation.md)。 |
| AN-06 模型覆盖、内建动作桥接与解析复用 | Hybrid 选择模型声明的 controller，未覆盖行为保留 coded/default。运行时 controller 自有来源与结果 map，多个 player 共用解析，子 controller 独立；资源重绑定与使用结束清除缓存。删除桥接会丢失基础动作；删除缓存只增加共享查询，不改变播放语义。缓存增加来源失效责任，成功引用和缺失 key 随不同名称数量增长，无容量上限。 | `D-CONTROLLER`、`D-VANILLA-ACTION`、`D-AN-FALLBACK`；桥接为 **Essential**，解析缓存为 **Derived**。 | **Fact**：`HybridAnimationController`、`ControllerAnimationCache` 与 controller collection；[播放选择](../../architecture/animation/controllers-and-playback.md)、[资源裁决](../../architecture/model-management/client-resources/implementation/resource-ownership.md#动画解析与保留)、[默认回退](../../product-decisions/decisions/model-fallback.md)。真实 Coded／Bedrock 定向序列证明预热后减少共享解析且不建 read batch；predicate 旁路仍访问资源，吞吐与保留字节未测。多种 controller 不按实现类数重复计数。 |
| AN-08 现存并行动画的旋转混合补丁 | Parallel controller 仍启用 `blendRotation` 与 cached point accumulation；删掉会改变其数值结果，但尚无受保护作品样本说明所需结果。 | 根理由缺口 `H-BLEND`；**Uncertain**。 | 存在性及源码注释所述“解决一个历史遗留问题而保留的动画混合”“旧版 blendRotation 只有高并行动画在用”为 **Fact**：`AnimationProcessor`、`CodedAnimationController`。原问题是否消失未知，不能标 Historical；兼容等级见 [Q-06](open-questions.md#q-06)。 |
| AN-09 生成依赖级兼容 checker | 编译期分析拥有代码与依赖，生成 checker/probe/manifest；直接删除生成端会使当前 runtime 因缺失 checker 跳过 handler。 | `A-AN-04`；**Derived**。 | **Fact**：`ExtensionCompatibilityProcessor.finishCompilation`、`CompatibilityAnalyzer.analyze`、`CheckerSourceGenerator`；[扩展注册](../../architecture/integration/implementation/extension-loading.md#扩展兼容检查与注册)。可选降级能解释门禁，不能独自证明完整生成管线的收益，见 [Q-07](open-questions.md#q-07)。 |
| AN-10 先检查再加载及局部失败隔离 | Checker 接受前不初始化 handler；Molang collector 先验证安全资源、all-of 依赖和 auto/manual 资格，后解析/初始化/绑定，拒绝全部冲突类，终态后冻结 registry。链接/构造/注册失败按原 owner 隔离；内部 SW 手部采用确切 metadata 门禁、冷期构造/注册回滚与 getter linkage 隔离，不借用扩展 checker，不包围 YSM/consumer 输出。删除前置隔离会让不兼容可选代码提前初始化或传播 loader 错误。 | `D-EXT`；**Essential**。具体反射结果协议由 AN-09 派生，隔离义务不依赖生成器。 | **Fact**：`CompatibilityQualification`、`MolangExtensions.Collector.freeze`、`ExtensionEventHandlerRegistration.prepare`、`ExtensionEventHandlerLoader.registerOne`、`SWarfareCompat.registerHandAdapter`、`ReplacePlayerArmRender.readHost`；`ExtensionEventHandlerRegistrationTest`、`SWarfareHandAdapterTest`；[可选联动决策](../../product-decisions/decisions/integration-risk.md)。 |
| AN-11 连续顶点与宿主 consumer 的双路径 | 可识别布局走 direct，其他 consumer 走中间数组回放；删除 fallback 会丢失未知连续布局 consumer，删除 direct 则损失其优化。 | `A-NATIVE`；**Derived**。`D-OUTPUT` 约束路径等价，不强制两条路径的拓扑。 | **Fact**：`NativeRenderer.probeVertexConsumer/render`、`FallbackVertexWriter`；[顶点输出](../../architecture/rendering/implementation/vertex-output.md)。吞吐差异未量化；完整路径的视觉等价仍待[实机验收](../../status/known-issues/rendering.md#待验证场景)。 |
| AN-12 成功后提交宿主输出 | Direct 先 reserve，native 成功才 advance；fallback 成功才回放。同步 boolean 只在提交完成或经 native 校验的有效空结果时成功；外部容量/宿主矩阵及纯组合溢出拒绝保留姿态，publication 损坏才撤销资格并由 producer 恢复。删除门禁会提交 native 失败前的部分输出。 | `D-HOST`、`A-NATIVE`；**Essential**。 | **Fact**：`NativeRenderer.render`、`VertexBufferAccessor`、真实 JNI 输出集成测试与 native 四模式失败分类；[输出接口](../../architecture/rendering/implementation/vertex-output.md)拥有 source 校验与汇合规则。第一人称统一 renderer 复用同一 boolean，标准与 SW adapter 只在有效消费后取消该侧，背景从不取消宿主；hook 拒绝与缺根不作为合法空。实体求值失败不交付 Prepared；输出不使用 consumer 阶段标记或异常 relay。成功门禁不是 consumer 事务；回放异常按[产品失败边界](../../product-decisions/decisions/failure-isolation.md#bcrender-failure-does-not-corrupt-scene)原样交宿主，不返回正常 boolean。 |
| AN-19 Deferred capture 的求值快照与逆序排空 | `defer` 接纳已求值的有限 F32，复制为 owner 持有的 typed payload；动画上下文结束时逆序调用当前 target 的 handler，仅在该窗口允许动作。保留 live view 会读取被改写值，无界登记会扩大实体状态。 | `A-DEFER`；**Derived**，仅服务跨越 call-local 生命周期。 | **Fact**：`EntityExpressionRuntime`、`DeferredRequest`；[Molang Binding](../../architecture/animation/implementation/molang-runtime.md#binding-与-invocation)。Capture 绑定同轮安装和采样位置，回调重建顶层窗口，普通效果仍由同轮裁决；累计捕获上限限制递归登记。轮退出清除剩余 capture。Headless 验证不替代 Forge 排空时机验收。 |
| AN-20 模型声音作者登记、消费驱动播放与 prepared host adapter | 作者事件在同一 entity/controller manager 登记 pending/已提交 handle。默认播放用同一消费 Seam 完成准备、refill 和 loop；前缀满足请求时不建 decoder，实际缺口才恢复。Host 只消费 ready PCM，取消先 seal，worker 结束借用后清理。删除需求约束会提前恢复；把前缀末尾当 EOF 会截断声音；分裂 owner 会让 stop/force 越过准备窗口。外部后端仍完整接管，不形成 fallback chain。 | `D-SOUND`、`D-EFFECT`、`D-HOST`、`A-AUDIO-RETENTION`；**Derived**。可观察声音、once-only effect、精确 stop 与局部失败是义务，消费 Seam 和准备阈值可替换。 | **Fact**：`SoundInstanceManager`、`ClientAudioRuntime`、`PlaybackAudioStream`、`CustomSoundInstance`、`AudioBackend`；[声音触发](../../architecture/animation/controllers-and-playback.md#声音触发与宿主播放)与[消费与恢复](../../architecture/model-management/audio/overview.md#pcm-保留与发布)及[播放终态](../../architecture/model-management/audio/overview.md#播放终态)。测试入口断言缓存缺口、loop 与取消；当前运行范围和设备缺口见[支持状态](../../status/support-and-verification.md)。 |
| AN-21 共同声明与最终类型化计划 | builtin/API 共用声明 authority 和统一 context 签名；声明类拥有业务，runtime 不维护 symbol 或效果分类目录。可信来源接纳后派生普通与 builtin-only 视图，完整依赖和 effect 直接投影元数据。纯目标由声明指定，内部来源授权后进入精确 binding。Namespace 与已验证 mod 归属分离，组件仍按声明类和 owner 构造。有效类型与有限函数版本闭合后派生 presence、精确 carrier、复制与 export；main/arm 独立闭合调用需求；单元内按完整契约共享分析和 entry，来源清单独立保留。共享只读内容准备。安装缓存 SubjectBinding，provider 直接接收同一轮 context；typed consumer 与失败继续归原 entity owner；OOM 不写入普通内容的永久失败记忆。代价包括冷期分析与制品、prepared pin、安装资格及真实值复制。 | `D-ENTITY`、`D-EXT`、`A-AN-04`；**Derived**。值隔离、来源、失败与 owner 边界是义务；不要求逐调用 wrapper 或 provider 权限窗口。 | **Fact**：`DeclarationSchema`、`WholeUnitSemanticCompiler`、`StaticValuePlan`、`ExpressionBinding`、`EntityExpressionRuntime`、`EntityModelBinding`；[共同声明](../../architecture/animation/molang-declarations.md)、[静态语言](../../architecture/animation/molang-static-language.md)、[执行与失败](../../architecture/animation/implementation/molang-runtime.md)。Holder 的五个 hook 使用固定数组与成功 begin 前缀清理，正常分发成本为 O(N)；兼容纹理替换延续 holder。轮入口固定成本、表达式框架成本与 tail、boxed 返回、复制、效果和失败载荷应分开测量；删除显式包装不能证明净收益或零分配。Headless、原作品和 packaged/warm oracle 不替代 Forge 世界、声音实例或正式性能验收。 |
