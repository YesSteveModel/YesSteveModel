# Terms

按需要查询术语；本页只定义本目录树中的用法。

| 术语 | 本目录树中的含义 |
|---|---|
| 模型 | 由清单引用、组织并定义的资产集合，包括可渲染的几何体（Geometry）、与之适配的动画、动画控制器和纹理，以及 i18n 字符串、脚本与音效；清单同时包含模型配置、元数据等信息。 |
| Geometry、Cube、BoneTree | Geometry 是体素模型，由 Cube 构成，并由骨骼层级 BoneTree 组织；动画定义骨骼的旋转、缩放和位移。 |
| Render target | 模型内面向特定呈现用途组织的一组资产，例如人形（humanoid）、特定投射物（projectile）或特定载具（vehicle）；一个容器可以包含多个呈现目标。 |
| 定位组 | 模型用于定位手持物、披风等附着内容的一组部位，跟随相应骨骼姿态运动；它的缩放可以参与外观控制。 |
| 默认模型 | 内置且名为 `default` 的可靠性基线。人形出现严重错误时回退到默认模型，投射物与载具渲染失败时直接恢复宿主原版渲染。模型缺少部分动画而借用默认动画时，不切换整个模型。 |
| 模型列表中的“已加载” | 模型已经进入当前可见目录，不表示其全部资产已经下载、烘焙或常驻内存。 |
| Raw、容器、chunk、preamble | Raw 是可编辑的源资产；容器是导出的单文件模型制品；chunk 是容器中可独立定位的内容单元；preamble 是容器前缀，可用于独立验证容器结构描述，但不包含完整资产。 |
| `ModelId`、`ContainerId` | `ModelId` 同时标识模型来源和业务身份；容器的精确字节表示属于另一种等价关系，不能把视觉等价、来源相同与字节相同混为一种身份。`ContainerId` 在各子系统中的使用边界由架构文档约束。 |
| LocalPlayer、RemotePlayer | 二者都相对于单个客户端而言：LocalPlayer 是当前客户端操控的玩家，RemotePlayer 是该客户端观察的其他玩家；服务端维护权威状态，不以 LocalPlayer 称呼自己的服务端实体。 |
| 追踪、全量、增量 | 追踪指游戏为观察者建立对相关实体的状态接收关系；全量是当前同步范围内的完整状态，增量是该范围内的后续变化，二者都不是复制实体的全部数据。 |
| roaming、`ysm.sync` | 前者同步创作者声明的累积状态，后者转发瞬时事件；模组不自动判断脚本结果属于哪一类。 |
| PBR | 基于物理的材质与光照表现能力，在本目录树中由兼容的渲染联动提供。 |
